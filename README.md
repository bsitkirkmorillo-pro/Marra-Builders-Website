Marra Builders WordPress Theme

A custom WordPress theme that preserves the original Marra Builders Inc. design (Tailwind, Montserrat, hero video, dark mode) while replacing the old Node.js admin with WordPress.

Features: Projects and Articles post types with galleries, a "Site Content" page for editable homepage and footer text, a quote form that emails the office and stores requests under Messages, server-rendered pages with SEO metadata and JSON-LD, and a one-time content importer.

Requires: WordPress 6.0+ and PHP 7.4+ (tested target: PHP 8.3).
